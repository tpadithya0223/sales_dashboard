# Sales KPI Dashboard

## Overview
This project is an interactive Sales KPI Dashboard designed to monitor sales performance through key business metrics and visual analytics.

## KPIs
- Total Sales
- Total Profit
- Total Orders
- Total Quantity Sold

## Features
- Sales Trend Analysis
- Regional Sales Performance
- Category-wise Sales Distribution
- Top Performing Products
- Interactive Charts

## Technologies Used
- HTML
- CSS
- JavaScript
- Chart.js
